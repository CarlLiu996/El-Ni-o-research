## 可复跑入口

周一先执行常规官方源准备，再读取其最新完整交易日；不得从自然日猜交易日：

```bash
PYTHONPATH=src python -m agri_cta.weekly --data <私有数据根> --end <官方最新完整交易日>
```

此入口采集新浪公开逐合约日K，端点由AKShare公开源码`futures/futures_zh_sina.py`的`futures_zh_daily_sina`核实。默认合约为九品种及NR的2701/2705，属于明确研究合约，无隐含主连拼接或换月。合约到期后须显式调整合约参数，不能自动延续。
