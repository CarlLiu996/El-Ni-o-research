## 结构

### 1. 首页九品种“多品种总览”

逐品种固定字段：
`symbol, account_tag, last_known_stage, old_rating, new_rating, changed_rating, newly_disclosed_evidence, valuation_view, valuation_confidence, safety_margin, concentrated_setup, source_cutoff, missing_data`

- 阶段：预期形成/基本面验证/价格确认/趋势启动/逻辑证伪。
- 星级：★–★★★★，若没有★★★★写“今日无★★★★集中表达标的”。
- 估值来源：基差历史分位、近远月结构、生产/压榨成本、进口利润、相对价差、库存-价格关系；若无合法真实序列写“仅做方向判断”。
- 今日无证据 = `本次未取得可核实关键新增`，**不等于客观市场没有变化**。

### 2. 新增证据账本（机器可读）

`evidence_ledger.csv` 推荐字段：
```
report_date,symbol,metric_id,source_id,source_url,observation_date,published_at,
fetched_at,old_observation_date,old_value,new_value,unit,delta,percent_delta,
vintage,evidence_tag,already_reported,meaningful_change,impact_dimension,
bull_bear,contradictory_evidence,verification_status,quality_issues
```

每个品种即使无关键新增，也应有 source_coverage 日志，包含**已查具体指标、是否有新披露、源访问失败、授权不足、未能核验的数据截止日**。

四种标记：
- `TODAY_NEW` / 【今日新增】：两次冻结时点之间正式新增披露或修订且具可核验时间。
- `WEEK_NEW` / 【本周新增】：本周较早已发布但未写过日报且仍需解释，注明初次披露日（不能叫“今日”）。
- `CONTINUING` / 【延续信号】：已披露且已有报道，解释与新信息的关系。
- `BACKGROUND` / 【旧数据/背景】：纯背景，不当作新数据。

### 3. 正文：变化品种优先

每个值得分析的品种，不受固定字数限制，写：
- **供应/成本变化**：何日披露，量/成本/天气/政策的新增；
- **需求和库存**：直接证据，销量/开工/到港/库存/仓单变化；不要把仓单注销自动认定为去库；
- **现货/基差/月差/外盘**：注明品种、期价类型、合约月份、数据日期，区分期权IV和期货行情；
- **冲突证据、估值、CTA操作及证伪条件**：已交易多少预期？风险收益对称吗？为何升降或维持星级？

每个品种数据覆盖率可在附表/QA中，而不是用“无变化”替代根本未查。

### 4. 正文图表：日度增量与周度固定观察

- 2026-11-25用户进一步要求延长观察区间并改善简陋的展示。主图默认完整可核实历史，优先3—5年、日频优先至少一年；历史不足明确标实际区间。近三个月放大仅作辅助，n=2及字符条形图只作短期比较或兼容保底，不能代替主图。
- 统一时间轴、数值轴、单位、最新值、系列图例和来源标注；有合格月度历史时增加同月季节性比较，未披露月份留空。日期定位展示原始观测，图形先静态存在，交互只作增强。可复用无数据模板`templates/long_history.html`。
- 当前可展示MPOB 46个月、RU/NR约一年仓单，以及不足一年的指定合约结构；这不是九品种三年产业覆盖。日常仍按新增变化选择重点，样式样本默认展开棕榈油不表示每日重复旧MPOB图。

- 2026-11-25用户再次反馈内嵌图没有显示。图表载荷通过数据校验不等于客户端图形已显示；可见性单独记录，不能把本地浏览器检查当作用户设备的显示回执。
- 默认使用含直接可见静态SVG/HTML标记的图表，外部脚本和交互只能增强，不能是关键图形首次出现的唯一条件。可用浏览器时检查实际非空图形、320/736px和明暗主题。
- 本任务含图正文同时保留紧凑字符条形备用图，使用已核实前后值、日期、单位、样本数和统一比例尺；它不代替合格长历史图。客户端未显示内嵌图时仍能在正文看到变化，不能只重复图表引用或文件路径。继续不另发PNG图片包。

- 2026-11-24用户要求保留“经核实的实质新增变化才画日度增量图”，另增每周九品种固定观察图。每周一08:00在同一份日报中展示，不另设重复推送；休市标最新实际统计日，不能假造周一盘面变化。
- 周度固定图即使无新增也展示，标“周度持续观察/历史背景”；每品种优先固定2—3项能检验供需判断的指标，便于逐周比较。产业序列不足时，允许用明确固定合约的价格/月差/跨品价差临时代替，并列出产业缺口，不能据此声称供需验证完成。
- 每周优先：SR广西产销库存/基差/月差；CF公检每日新增与累计分列、仓单/纺企库存/月差；RU/NR各自仓单、青岛库存、原料/轮胎开工；M豆粕库存/实际压榨/基差；C港存/收购到货；P的MPOB三项/港存/Y−P；Y豆油库存/压榨/Y−P；OI菜油库存/进口利润/OI−Y；RM菜粕库存/成交/M−RM。
- 专业来源必须注明未完成交易所交叉核验的范围，不与官方序列混接。补取于07:50之后的记录不倒填当日晨报。每品种无合格数据则保留缺口，不画假图。

- 用户于2026-11-18认可真实样本，并明确要求图表直接展示在每日报告正文，不专门另做或发送图片包。优先使用宿主原生/内嵌交互图，关键图不只给附件或文件链接。
- 内部归档允许保留必要图片和计算产物，但不把PNG制作与发送当成用户交付要求。宿主确实不能呈现图时，说明限制并在正文给可读数据表，不声称图已显示。
- 日度增量图只选择 `meaningful_change=true` 且有解释力/完整时序的数据；周度固定图独立于此条件，仍须通过来源、时间、单位和样本质量核验。
- 能取到1年或3年的真实数据则选1y/3y历史位置和同期季节性。按同品质、地区、单位、交易价格类型。
- 图上标注最新点、来源、样本区间、频率、缺失率、n、发布日期。
- 每图四段短注：最新变化、历史位置、供需解释、CTA操作含义/证伪条件。
- 历史数据不够，正文给证据，但不画伪图或杜撰分位。两个时点的真实前后对比可展示，明确n=2，不称为长期历史或趋势。
- 待核网页摘要不进入已验证数值图；旧月报背景图不每日重复，样本展示不自动变成日报固定图。
