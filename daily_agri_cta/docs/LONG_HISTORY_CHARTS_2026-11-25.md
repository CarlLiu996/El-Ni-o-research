# 长历史图表样式与覆盖边界

用户反馈此前两三天备用图区间过短、样式简陋。新增数据与周度固定观察的原有触发条件保持，默认主图改为完整可核实历史，短期放大折叠展示。

`templates/long_history.html`是无市场数据的共享样式模板，替换`__ROOT_ID__`、`__ASOF_NOTE__`、`__PRODUCTS__`及`__DATA__`后使用。基础SVG已经存在，日期定位交互不依赖外部图表库；禁用脚本仍显示基本图形，品种原生折叠面板也可展开。

本次私有样本包含九品种：MPOB库存/产量/出口2023年1月至2026年10月各46个月及四个年份的同月库存对照；RU/NR各249个日频仓单；其余指定合约结算价与同日价差按实际127—204个交易日展示。合约不换月、不拼主连、缺失不补值。2026年11—12月MPOB无已核实月度值，季节图留空。

更早橡胶仓单曾通过现有官方日文件路径检查2023/2024两个交易日，均返回404；本次没有补齐更早连续日频历史，也没有用孤立旧点冒充多年连续库。单一专业行情尚未完成交易所逐条交叉核验。原始稿、晨间冻结及研究评级未修改，产业P0验收不因图表改版而改变。

数据、完整曲线、原文与截图均留私有目录。公开仓库只提交无数据模板、输出规则及覆盖说明；截图用于本地显示检查，不作为单独PNG包交付。

样本验证：引用的265个原文件哈希及2776个实际观测核验通过；九品种在320/736/1024宽度与明暗主题共54个显示组合通过。日期首末定位、未披露月份不补值、近三个月放大、初始不写入交互状态，以及禁用脚本时的基本图形和原生品种展开也已实际验证。本地浏览器检查不等于用户客户端显示回执。
