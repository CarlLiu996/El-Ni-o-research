## 目标与不变约束

把每天北京时间 **08:00** 的农产品主观 CTA 九品种日报，从“逐次网页检索”改为“**可追溯的数据管道 + 持久化历史数据库 + 首次披露/边际变化识别 + 研究报告**”。

- 九品种：白糖 SR、棉花 CF、天然橡胶 RU（兼查 NR）、豆粕 M、玉米 C、棕榈油 P、豆油 Y、菜油 OI、菜粕 RM。
- 自有资金可交易：SR、CF、C、RM；CTA 管理人研究/策略可交易：RU/NR、M、P、Y、OI。
- 研究结论必须判断：预期形成 → 基本面验证 → 价格确认 → 趋势启动 → 逻辑证伪。方向评级 ★～★★★★，只在供应/需求、库存、现货/基差/月差、价格趋势交叉验证后升级。
- **“有新增数据”不等于“评级变化”；“评级未变”不能成为不写产业变化的理由。** 未查询到数据要写“本次未取得可核实更新”，不能写“客观无变化”。
- **同一天数据必须留“所属交易日/统计期、发布时间、实际采集时间”三种日期**，保留官方修订版本。旧周/月数据不能混成昨天发生的变化。
- 基差 = 地区/质量明确的现货价 − **同一时点/交易日**的指定期货合约价（标明收盘/结算）；月差 = 明确指定的近月合约 − 远月合约（通常 2701−2705），同价种。
- 历史图：只对确有实质边际变化的指标作真实历史 3个月/1年/3–5年序列/同期季节性和分位，缺失/换口径/换月需标注，不得画假样本。
- 终稿最末固定附国投期货交易提示/公司保证金与涨跌停板**变动监测**，期货公司客户标准与交易所标准不能混淆。

### 推荐时序（北京时间，具体发布时间以源为准）

| 时间 | 任务 | 关键动作 |
|---|---|---|
| 历史回填（一次/补缺） | 取过去3–5年/上市以来 | 官网页面、文件、授权数据批量采集，保存原始快照 |
| 交易日盘后 18:00–23:00 | 日频期货/仓单入库 | 记录数据交易日、结算价/收盘价/持仓量、首次公布日 |
| 次日 06:45–07:35 | 增量补录产业资讯 | 夜盘、海外数据、前日已披露周/月数据，不倒填发布时间 |
| 07:35–07:50 | 数据完整性及新增证据扫描 | 相比上一**有效披露**和前期报告，识别真正的新变化 |
| 07:50 前 | 冻结当期「可用数据截至时点」 | 无效/未核实的数据只列缺口，不给假值 |
| 08:00 | 现有自动化推送日报 | 不更改现有 ChatGPT 任务，直到云端链路验收 |

**注意：** GitHub Actions 的 UTC cron 可用于自动采集，但不保证准点执行，也不能直接保证 ChatGPT 08:00 准点读取；上线前须单独验证报告投递接口。初期可用 Actions 的 \`workflow_dispatch\` 手动运行。

## 成功验收

1. 可演示 **至少一条官方MPOB、一个中国交易所行情/仓单、一个NOAA** 真正历史系列，含来源网址、原始快照、初次采集时间。
2. 可执行离线回放：重新运行相同交易日不产生重复数据；官方修订不会覆盖旧版，而是增加 vintage。
3. 证据账本能区分：观测日早于披露日、昨日新增披露、旧数据重复、新增数据但评级不变。
4. 按同合约同交易日正确计算基差/月差，缺数据不计算；有完整历史才计算分位。
5. 国投只记录正式公告确认的 **公司客户实际费率变化**，旧值缺失标记 \`unknown\`，不把交易所标准当公司标准。
6. 与旧任务 **并行试运行至少5个境内交易日**，对比漏报率、延迟、错误引用；通过后再讨论自动交付对接。
