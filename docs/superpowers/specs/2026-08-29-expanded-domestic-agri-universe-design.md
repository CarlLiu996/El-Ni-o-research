# 国内农产品期货扩品种取数与厄尔尼诺复盘设计

## 1. 目标与边界

在现有八页领导汇报工作簿和“气候天气 → 供给基本面 → 市场定价 → CTA 可捕捉性 → 数据审计”的研究链上，把研究范围从棕榈油、白糖扩展到中国期货市场可交易的八个合约：棕榈油 `P`、白糖 `SR`、棉花 `CF`、玉米 `C`、豆粕 `M`、豆油 `Y`、菜籽油 `OI`、菜籽粕 `RM`。

本期需要交付可持续更新的数据、历史复盘、价格与 CTA 代理，以及更新后的八页 Excel。研究先回答“哪些作物链存在可重复的厄尔尼诺传导条件、市场何时定价、既定趋势策略能否捕捉”，不把挖掘到的历史规律自动写入当前 CTA 配置建议。是否使用历史规律修正配置置信度，仍由用户审阅复盘结论后另行决定。

本期不纳入境外独有且中国期货市场没有直接交易合约的咖啡、葵花籽等品种；不为凑齐指标而使用无法审计的抓取值，也不把研报预测当作历史实现值。

## 2. 方案选择

采用“分层最小可复现”方案：先完成八个国内合约的正式行情和 CTA 代理，再补四次重点事件的长期价格及基本面，随后按作物生育期加入天气，最后做跨层复盘并重建 Excel。

没有采用以下两种方案：

- “全部数据齐备后统一分析”：时点基本面、长期菜籽价格代理和部分主产区遥感可能缺失，会让已可交付的国内行情长期等待。
- “只扩价格不扩基本面”：虽然快，但不能检验气候冲击是否穿透库存和需求缓冲，也无法回答研究项目的核心问题。

分层方案允许每个阶段独立验收；后续来源暂时不可用时，已经取得的正式行情、CTA 和历史资料仍可进入数据审计与工作簿。

## 3. 研究对象与计权规则

### 3.1 六个作物链、八个合约

| 作物链 | 国内合约 | 交易所 | 研究角色 | 主要外部产区 |
|---|---|---|---|---|
| 棕榈油 | `P` | 大连商品交易所 | 高敏感度主研究对象 | 印度尼西亚、马来西亚 |
| 白糖 | `SR` | 郑州商品交易所 | 高敏感度主研究对象 | 巴西、印度、中国 |
| 棉花 | `CF` | 郑州商品交易所 | 扩展研究对象 | 美国、印度、巴基斯坦、中国新疆 |
| 玉米 | `C` | 大连商品交易所 | 低敏感度对照与条件性机会 | 美国、巴西、阿根廷、中国东北 |
| 大豆产业链 | `M`、`Y` | 大连商品交易所 | 同一原料冲击的不同加工端 | 美国、巴西、阿根廷、中国进口压榨 |
| 菜籽产业链 | `OI`、`RM` | 郑州商品交易所 | 同一原料冲击的油粕两端 | 加拿大、澳大利亚、欧洲、中国 |

### 3.2 避免重复计权

工作簿保留八个合约各自的价格、波动率和 CTA 路径，但跨品种结论只按六个作物链计数：

- `M` 与 `Y` 分别展示，产业链确认值由两者等权汇总；无论两者是否同向，只贡献一份大豆链证据。
- `OI` 与 `RM` 使用相同规则，只贡献一份菜籽链证据。
- `P`、`SR`、`CF`、`C` 各贡献一份独立证据。
- 因油粕利润、替代关系或需求差异造成同链分化时，结论写为“链内分化”，不得强行平均成明确方向。

暂不加入黄大豆一号、黄大豆二号和油菜籽期货，避免扩大到流动性、进口定价和合约连续性更复杂但不能显著增加独立证据的合约。

## 4. 数据架构与来源优先级

### 4.1 统一品种配置

新增统一配置文件，至少包含：作物链、合约、交易所、产业链角色、主要产区、生育期、研报提出的传导假设、所需基本面、允许的数据源、正式或代理属性、覆盖起点和更新频率。

所有下载器和 Excel 生成器读取这一份配置，禁止在脚本中分别维护不一致的品种名单。

### 4.2 国内期货正式行情

正式结论优先使用 Tushare Pro 的 `fut_daily`、`fut_mapping` 和 `fut_basic`：

- 下载合约级日行情、主力映射和合约元数据；
- 构造连续主力序列时，换月日使用同一合约的前后收盘价计算收益，禁止直接把旧主力价格与新主力价格相除；
- 原始合约行情、主力映射、连续收益和下载清单分别落盘；
- Wind 可作为缺口校验或 Tushare 不可用时的正式备选；
- AkShare 等免 Token 行情只能标记为探索性数据，不进入正式 CTA 结论，除非能够证明合约、换月和历史修订口径。

每个数据文件保存 `source`、`retrieved_at`、`data_as_of`、代码、交易所、主键检查和下载状态。缺少映射或单日合约行情时保留缺口，不用前值伪造收益。

### 4.3 长期历史价格

国内期货上市前的四次事件无法全部使用中国期货合约，需要建立“描述性国际价格代理”和“可执行国内期货”两层：

- 国际长期代理优先使用 World Bank Pink Sheet、IMF、FAO 或其他官方公开月度序列；
- 棕榈油、糖、棉花、玉米、大豆、豆油分别寻找定义稳定的国际基准；
- 菜籽链只有在来源、单位和连续性可审计时才使用国际菜籽或菜籽油代理，否则该事件保持价格缺失；
- 所有国际代理明确标注“历史价格代理”，不得与国内合约收益拼接成一条可交易回测；
- 国内合约自可靠覆盖起点起，单独计算日频价格和 CTA 结果。

### 4.4 基本面数据

基本面按六个作物链回答供给、需求、库存三个问题；研报只用于提出假设和选择产区，表内正式数值必须能追溯到外部数据或项目计算。

| 作物链 | 供给 | 需求 | 库存与缓冲 |
|---|---|---|---|
| 棕榈油 | 产量、单产 | 出口、消费 | 期末库存、库销比 |
| 白糖 | 甘蔗或糖产量、单产、制糖比例 | 消费 | 期末库存、库销比 |
| 棉花 | 产量、单产 | 消费、出口 | 期末库存、库销比 |
| 玉米 | 产量、单产 | 饲用、乙醇或工业消费、出口 | 期末库存、库销比 |
| 大豆链 | 大豆产量、单产 | 压榨、出口；分别解释豆粕和豆油需求 | 大豆及相关油粕库存、库销比 |
| 菜籽链 | 菜籽产量、单产 | 压榨、进口、出口；分别解释菜油和菜粕需求 | 菜籽及相关油粕库存、库销比 |

来源按“国家或行业官方机构 → USDA PSD 等国际官方数据库 → 可审计行业数据库 → 研报事实引用”排序。预测值、估计值和实际值必须分列。

用于历史描述的最新修订年度数据库可以展示，但若没有当时的发布版本或 `available_at`，不得进入无未来函数因子检验。进入回测的基本面记录必须保存实际发布时间或可证明的最早可得日期；否则标记为 `DESCRIPTIVE_ONLY`。

### 4.5 天气、遥感与生育期

天气不按整个厄尔尼诺事件机械平均，而按各作物主要产区的播种、生长、开花、灌浆或成熟关键窗口计算：

- 棉花：美国南部和得州、印度 Gujarat/Maharashtra、中国新疆；巴基斯坦只在数据质量足够时纳入。
- 玉米：美国 Corn Belt、巴西 Mato Grosso/Parana、阿根廷 Pampas、中国东北。
- 大豆：美国中西部、巴西中西部和南部、阿根廷 Pampas。
- 菜籽：加拿大 Prairies、澳大利亚西部及新南威尔士、欧洲主要产区、中国长江流域。
- 棕榈油和白糖沿用现有印马、巴西、印度和中国代表区，并保留印度季风与糖蔗 NDVI 代理。

主要变量使用 NASA POWER 的降雨、温度、土壤湿度等可持续序列；NDVI 只有在产品覆盖、质量标记和鉴权稳定时使用。每个作物阶段保存窗口、基准期、异常值、有效区域数和数据状态。缺少可靠种植区掩膜时只能称为“主产区植被代理”，不得称为作物专属长势。

## 5. 历次厄尔尼诺复盘方法

### 5.1 重点事件与完整样本

领导版重点展示研报选择的四次代表性事件：`1982/83`、`1997/98`、`2015/16`、`2023/24`。表内单独列示 NOAA 口径的峰值强度和持续期，不预先把四次全部称为“超强事件”。选择它们是为了覆盖高强度案例、不同市场环境和近现代数据条件，而不是为了证明它们必然产生相同商品结果。

结构化研究数据仍保留数据可得范围内的全部已完成厄尔尼诺事件，作为稳健性和反例检查；额外事件不挤占领导版主表。当前未完成事件不进入历史胜率和阈值挖掘。

### 5.2 统一证据链

每个“事件 × 作物链”依次回答：

1. 关键生育期是否出现方向和强度明确的天气异常；
2. 相关主产国产量或单产是否偏离事件前可得基准；
3. 库存、进口、替代品和需求是否吸收或放大供给冲击；
4. 国际代理和国内期货是否、何时开始定价；
5. 固定规则的 Fast、Medium、Slow CTA 是否在扣除成本后捕捉趋势。

任一环节不成立都记录为链路断点，不从 ENSO 强度直接推导商品方向。

### 5.3 对齐窗口与结果指标

气候 `T0` 使用事前可识别的 NOAA 事件起点；作物层同时保留本地作物季相对时间。每个事件输出：

- 天气关键窗口异常和历史分位；
- 产量、单产、消费、库存及库销比的同比和相对事件前五年中位数偏差；
- 价格 `0—3`、`0—6`、`0—12` 月收益、最大上涨、最大回撤、趋势持续时间；
- CTA `0—3`、`0—6`、`0—12` 月成本后收益、最大回撤、正收益月份比例和换手；
- 数据覆盖率、实际/预测属性、是否满足当时可得和缺失原因。

领导版只总结跨事件重复出现的条件，不把四个小样本的平均值包装成确定规律。少于三个有效事件时写“证据不足”；三个有效事件只能写“有限样本倾向”；至少四个有效事件且方向一致比例达到 70% 才写“较稳定历史模式”。

## 6. CTA 代理与产业链确认

国内日频 CTA 沿用固定定义：

- Fast：20/60 日趋势；
- Medium：60/120 日趋势；
- Slow：120/250 日趋势；
- 信号在收盘后形成，下一交易日执行；
- 年化目标波动率统一为 20%，最大绝对杠杆为 2 倍，按绝对仓位变化收取每单位换手 2 bps 成本；
- 任何滚动波动率、均线和仓位都只能使用当时及以前的数据。

“多品种、中慢速同向确认”改写为可核验规则：

- 单合约层：分别展示 Fast、Medium、Slow，不因 Fast 单独反转就称为趋势确认。
- 作物链层：Medium 与 Slow 同向才形成该合约的中慢速确认；大豆链、菜籽链还要求两只合约方向一致，否则为“链内分化”。
- 组合层：按六个作物链计数，不按八个合约计数。组合确认用于描述趋势环境广度，不自动决定多空方向或当前配置。

历史价格代理构造的月频 CTA 只回答“趋势规则能否捕捉长期国际价格路径”，与国内可执行日频 CTA 分列，不拼接业绩。

## 7. 因子研究与结论纪律

研究检验以“条件性机会”而非“厄尔尼诺固定方向”为核心：

- 单独检验天气、基本面、库存缓冲、市场确认和 CTA 收益之间的先后关系；
- 对产区和生育期做预先定义，禁止看到收益后移动窗口；
- 2015 年以后数据在覆盖允许时保留独立验证期；
- 报告正结果、负结果、反例、样本量和多重尝试，不只保存最优规则；
- 大豆链和菜籽链的两只合约不作为两份独立样本抬高显著性；
- 因子仅形成“候选规律”和置信度说明，不写入 `00_结论-CTA建议` 的配置动作。

在用户审阅扩品种复盘并明确批准前，当前 CTA 建议、配置置信度和 L1—L4 门槛不得读取新增历史因子结果。

## 8. Excel 交付设计

继续保持八张可见 Sheet，不新增 Raw Sheet：

1. `00_结论-CTA建议`：保留现行配置逻辑；增加“扩品种复盘尚未进入配置”的明确提示。
2. `01_总逻辑`：解释六作物链、八合约和气候至 CTA 的完整传导及断点。
3. `02_H_历次厄尔尼诺复盘`：突出四次代表性事件；展示“作物链 × 事件”结论矩阵、价格迷你图、CTA 净值迷你图、最可靠规律、反例和不能推导的结论。
4. `03_L1气候天气`：按作物关键产区和生育期展示天气、季风及可用 NDVI，解释指标含义和当前位置含义。
5. `04_L2供给基本面`：六个作物链分别用供给、需求、库存卡片展示；每张卡片包含当前值、同比或同季节位置、历史分位、方向、迷你趋势、数据日期、预测属性和方向判定理由。
6. `05_L3市场定价`：展示八合约最新价格、收益、波动率、期限或主力映射状态和迷你趋势；国际历史代理只用于复盘，不冒充国内最新行情。
7. `06_L4_CTA环境`：展示八合约三速度信号、20% 目标波动后的代理仓位、单合约中慢速确认、两条产业链的链内确认和六链市场广度。
8. `07_L5数据审计`：展示来源、覆盖、最新观测、发布时间、抓取时间、正式/探索/描述性属性、缺失原因和是否参与结论。

领导版不出现未经解释的 `FETCH_ERROR`、`AUTH_REQUIRED` 等代码。底层状态仍保留供审计，表面翻译为“接口暂时不可用”“鉴权失效”“产品尚未发布”“历史时点数据不存在”等中文原因，并同时说明对结论的影响和补数办法。

## 9. 文件与模块边界

计划新增或扩展以下边界，实际文件清单在实施计划中细化：

- `config/commodity_universe.json`：唯一的品种、产业链、产区和生育期配置；
- 国内期货适配器：下载合约行情、主力映射和合约信息，不负责研究结论；
- 基本面适配器：按来源下载并标准化产量、需求、库存和发布时间；
- 天气适配器：按产区和作物阶段输出异常值，不负责商品方向判断；
- 历史复盘模块：生成事件证据面板、价格路径、CTA 路径和链路断点；
- 因子研究模块：只读取处理后数据，输出候选规律及稳健性；
- Excel 生成器：只读取处理后文件，不在构建工作簿时联网。

新增数据优先落在：

- `data/processed/expanded_universe/`：标准化行情、基本面、天气、事件面板和 CTA；
- `research/expanded_universe/`：复盘表、研究结论、缺失清单和数据说明；
- `research/`：更新后的八页领导汇报 Excel。

所有联网刷新先落盘并写 manifest，分析和 Excel 可以离线复现。

## 10. 分阶段实施与取数顺序

### 阶段 A：国内期货价格与 CTA

先取 `CF`、`C`、`M`、`Y`、`OI`、`RM` 的 Tushare 合约行情、主力映射和合约资料，与现有 `P`、`SR` 合并；完成连续收益、Fast/Medium/Slow、20% 目标波动和产业链确认。阶段产物独立校验，便于尽快查看八合约价格与 CTA 覆盖。

### 阶段 B：四次重点事件的长期数据

取得六作物链主要国家的年度产量、单产、消费、库存和可用国际价格代理；对齐四次重点事件，同时保留全事件结构化控制样本。来源缺失时先生成缺失清单，不等待无期限补齐。

### 阶段 C：产区天气与生育期

按预先定义的产区和关键窗口取得降雨、温度、土壤湿度及可用 NDVI；计算同阶段异常和覆盖率，并与年度基本面连接。

### 阶段 D：跨层复盘与 Excel

生成事件证据面板、链路断点、候选规律、反例和 CTA 捕捉结果；重建八页 Excel，完成迷你图、中文解释、缺失原因和视觉检查。用户审阅结果后再决定是否另建 CTA 配置修正规格。

## 11. 失败处理与数据安全

- 单一数据源失败不得阻断其他品种刷新；运行结果为 `OK`、`PARTIAL` 或 `FAILED`，并逐项保存中文可读原因。
- 最近一次成功值只能按真实 `data_as_of` 和 `published_at` 展示，并明确标为过期，不得用本次运行时间冒充数据日期。
- Token、API Key 和请求头只从环境变量或 GitHub Secret 读取；代码、日志、CSV、Excel 和 manifest 均不得包含凭据。
- 用户在对话中提供过的 Token 不写入规格、代码、命令记录和仓库；执行时只使用已配置的安全环境变量。
- 预测、估计和实际值严格分列；历史复盘的已实现统计只使用实际值。
- 无法证明时点可得的数据不得进入无未来函数回测；可以作为事后描述，但必须显著标记。

## 12. 测试与验收

自动化测试至少覆盖：

- 八合约配置完整、交易所正确、六作物链计数且 M/Y、OI/RM 不重复计权；
- 合约行情和主力映射主键唯一、换月收益使用同一合约、缺口不伪造；
- Fast 20/60、Medium 60/120、Slow 120/250、下一日执行、20% 目标波动、成本和杠杆上限；
- 产业链确认规则和“链内分化”状态；
- 四次重点事件标签、NOAA 强度字段、当前未完成事件排除；
- 生育期窗口、跨自然年作物季、区域覆盖和气候基准期；
- 基本面实际/预测分类、`available_at`、描述性数据排除出回测；
- 价格代理与国内期货分列，禁止拼接为可交易业绩；
- 事件结果窗口、价格路径、CTA 净值、最大回撤和链路断点；
- 工作簿保持八张可见 Sheet，顺序正确，关键卡片和迷你图存在；
- Excel 不含公式错误、裸状态码、凭据或无法解释的空白；
- manifest、CSV 和研究结论可以在断网状态下重建工作簿。

本期完成的定义是：八个国内期货合约拥有可审计的最新价格、主力映射和统一 CTA 代理；六个作物链拥有结构化的供给、需求、库存框架及可得数据；四次重点厄尔尼诺复盘同时展示天气、基本面、价格和 CTA，并给出明确的规律、反例和证据强弱；八页领导版 Excel 保留迷你图、中文解释、缺失原因和数据日期；新增历史研究尚未自动改变当前 CTA 配置建议。
