## 先看清楚的事实

- 7 月末广西工业库存 221.34 万吨，上年同期 96.89 万吨；云南 90.65 万吨，上年同期 46.73 万吨。两省库存从 5 月至 7 月连续下降，但仍明显高于去年同期。“去库存”与“库存偏低”不是一回事。
- 广西累计产糖 769.74 万吨、销糖 548.40 万吨、销糖率 71.24%；云南分别为 293.83 万吨、203.17 万吨、69.15%。增产本身也会压低销糖率，不能把销糖率下降直接解释成终端需求下降。
- CASDE 8 月报告中，2025/26 年度产量 1,295 万吨是估计；2026/27 年度 1,293 万吨是预测。两者都不是已经实现的全国逐月生产量。
- CASDE “结余变化”是产量加进口、减消费和出口的年度平衡结果，不是可填入“期末库存”的数值。

## Excel 怎么读

1. 首页增加国内白糖证据提示，区分工作簿补充日与原监控快照日；不伪装为所有数据均已刷新。
2. L2 优先展示国内实际、全国年度背景、进口传导，然后保留海外样本六格和扩品种明细。
3. 每个省级指标展示最新值、迷你图、上年同期、同比变化、方向计算依据、观察日期、发布日期、可点击来源与限制。
4. 国内迷你图是同一榨季 5—7 月的实际路径；年度背景迷你图是同一榨季估计值的发布版本修订，不能当月度产量趋势。
5. 近月历史不够长，国内季节分位明确不计算。国内“方向”仅描述同比增减，与海外六格按分位判断松紧的规则分开。
6. L5 明列全国实际产销库存、长期同月样本和进口成本缺口；不会因接口返回成功就声称数据齐全。

## 重跑与持续维护

在仓库根目录，设置 `PYTHONPATH=src` 后运行：

```powershell
$env:PYTHONPATH='src'
.venv\Scripts\python.exe scripts/fetch_china_sugar.py --as-of 2026-08-31
.venv\Scripts\python.exe scripts/build_research_workbook.py --as-of 2026-08-31
```

加 `--offline` 可用原始缓存复核解析，但不会标记为本次联网刷新。

来源清单是 `config/china_sugar_sources.json`。当前尚未设置定时任务，也未实现新闻目录的自动发现；每次新月报需登记新 URL 与观察月，再运行取数。不能把重跑旧 URL 说成已自动补入最新月报。

解析检查包括：地区及观察月份、真实发布日期、单月与累计值区分、产量减销量与工业库存的勾稽、销糖率校验、预测与估计分类、发布日期截止过滤。云南原文库存与产量减销量有 0.01 万吨四舍五入差异，保留原文值，不用计算值覆盖。

## 仍需补齐，不能作出的结论

- 全国实际月度产销、全国同口径库存与多年同月样本尚未取得；省级工业库存不包括商业库存、进口加工糖和储备。
- 海关原始月表与当前进口成本、配额及政策约束尚不完整，不能计算可靠的当前进口利润或海外冲击传导比例。
- 以上证据并不识别厄尔尼诺的因果影响，也不改变正式历史回测或当前 CTA 配置权限。下一步应补同口径全国实际及进口链路，而非把预测填成实际、把销量填成消费。
